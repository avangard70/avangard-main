# Изображения для слайдера сертификации

Положите картинки прямо в эту папку: `public/certification/`.

Поддерживаются JPG, JPEG, PNG, WebP, AVIF и GIF. Имена могут быть любыми, включая кириллицу. Файлы показываются по имени с учётом чисел: `01.jpg`, `02.jpg`, `10.jpg`. Вложенные папки и остальные файлы игнорируются.

Список файлов читается автоматически при открытии `/certification`. Менять код и вручную перечислять картинки не нужно. Изображения показываются целиком без обрезки. Пока картинок нет, выводится заглушка; для одной картинки стрелки скрыты.

В режиме разработки (`npm run dev`) после добавления картинок обновите страницу. Если превью запущено через `npm run start`, после добавления файлов перезапустите сервер: Next.js запоминает список доступных файлов при запуске. Для опубликованной версии добавьте файлы перед сборкой и заново разверните проект; при использовании Docker папка копируется в образ.
